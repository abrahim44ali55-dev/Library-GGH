UI Elements

Comprehensive breakdown of available interface components and their core functionalities.

Element Functionality
Tab / Section Organizes the window into structured categories and navigation panels.
Button Executes a specific callback function instantly upon interaction.
Toggle A boolean switch state (True/False) utilized for persistent execution loops.
Slider Allows precise configuration of dynamic numerical parameters and thresholds.
Dropdown Provides a selective list of predefined configuration options.
Textbox Enables custom text input entry during runtime execution.
