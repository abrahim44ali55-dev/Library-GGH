WindUI Framework Documentation

Complete official-style documentation covering loadstring setup, window configurations, all UI elements, built-in themes, and advanced practical script examples.

1. Loadstring Initialization

Fetch and initialize the library securely using your repository raw link.

local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/abrahim44ali55-dev/Library-GGH/refs/heads/main/BEST/2026/Nice"))()

2. Window Setup

Initialize the main graphical interface window.

local Window = Library:CreateWindow({
    Title = "WindUI Library",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

3. Themes & Customization

Switch between available visual styles and color themes dynamically.

Dark Theme:

Library:SetTheme("Dark")

Light Theme:

Library:SetTheme("Light")

Midnight Theme:

Library:SetTheme("Midnight")

4. Core UI Elements Syntax

Base structural elements for organizing your interface.

Tab:

local Tab = Window:CreateTab("Tab Name")

Section:

local Section = Tab:CreateSection("Section Name")

Button:

Tab:CreateButton({
    Name = "Button Name",
    Callback = function()
        print("Clicked")
    end
})

Toggle:

Tab:CreateToggle({
    Name = "Toggle Name",
    Default = false,
    Callback = function(State)
        print(State)
    end
})

Slider:

Tab:CreateSlider({
    Name = "Slider Name",
    Min = 0,
    Max = 100,
    Default = 50,
    Callback = function(Value)
        print(Value)
    end
})

Dropdown:

Tab:CreateDropdown({
    Name = "Dropdown Name",
    Options = {"Option 1", "Option 2"},
    Default = "Option 1",
    Callback = function(Selected)
        print(Selected)
    end
})

Textbox:

Tab:CreateTextbox({
    Name = "Textbox Name",
    PlaceholderText = "Type here...",
    Callback = function(Text)
        print(Text)
    end
})

5. Practical Examples & Full Scripts

Ready-to-use full script implementations with live logic features.

-- Full Example: WalkSpeed & JumpPower Script
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/abrahim44ali55-dev/Library-GGH/refs/heads/main/BEST/2026/Nice"))()

local Window = Library:CreateWindow({
    Title = "WindUI Hub",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

local Tab = Window:CreateTab("Main")

Tab:CreateSlider({
    Name = "WalkSpeed",
    Min = 16,
    Max = 200,
    Default = 16,
    Callback = function(Value)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = Value
    end
})

Tab:CreateSlider({
    Name = "JumpPower",
    Min = 50,
    Max = 300,
    Default = 50,
    Callback = function(Value)
        game.Players.LocalPlayer.Character.Humanoid.JumpPower = Value
    end
})
