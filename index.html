UI Framework Documentation

Comprehensive English documentation, UI elements reference, themes, and full production-ready templates for developers and AI assistants.

1. Loadstring Initialization

Fetch and initialize the UI library securely using your repository raw link.

local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/abrahim44ali55-dev/Library-GGH/refs/heads/main/BEST/2026/Nice"))()

2. Window Setup

Initialize the main graphical interface window.

local Window = Library:CreateWindow({
    Title = "UI Library",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

3. Themes & Configurations

Switch between available visual styles and color themes for your interface layout.

Dark Theme Setup:

Library:SetTheme("Dark")

Light Theme Setup:

Library:SetTheme("Light")

4. Core UI Elements

Standard base syntax for creating individual components.

Tab:

local Tab = Window:CreateTab("Tab Name")

Button:

Tab:CreateButton({
    Name = "Button Name",
    Callback = function()
        -- Code here
    end
})

Toggle:

Tab:CreateToggle({
    Name = "Toggle Name",
    Default = false,
    Callback = function(State)
        -- Code here
    end
})

Slider:

Tab:CreateSlider({
    Name = "Slider Name",
    Min = 0,
    Max = 100,
    Default = 50,
    Callback = function(Value)
        -- Code here
    end
})

5. Practical Examples & Full Scripts

Ready-to-use practical script implementations with live logic (such as WalkSpeed adjustment) to copy and send directly to developers or AI.

-- Practical Example: Complete Script with WalkSpeed Slider
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/abrahim44ali55-dev/Library-GGH/refs/heads/main/BEST/2026/Nice"))()

local Window = Library:CreateWindow({
    Title = "Advanced Script Example",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

local Tab = Window:CreateTab("Main")

Tab:CreateButton({
    Name = "Print Notification",
    Callback = function()
        print("Button executed successfully!")
    end
})

Tab:CreateSlider({
    Name = "WalkSpeed",
    Min = 16,
    Max = 200,
    Default = 16,
    Callback = function(Value)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = Value
    end
})
