2. Window Creation & Configuration (`Library:Create`)

The core window acts as the primary canvas container for all tabs, elements, floating notifications, and key modals. You configure its properties by passing a configuration table.

  • Title: Defines the main name string shown on the top bar header.
  • Description: Adds secondary context or versioning separated by a stylized divider line.
  • Theme: Sets the initial active theme palette (defaults to "Dark Modern").
  • KeySystem: A boolean value (true/false) determining whether the script requires key authorization before displaying the main GUI.
  • Key: The correct target string that validates the user input inside the key overlay system.
local Window = Library:Create({
    Title = "Global Control Panel",
    Description = "Advanced & Comprehensive System",
    Theme = "Dark Modern",
    KeySystem = true,
    Key = "VIP-2026"
})

4. Core UI Elements & Native Methods

After creating your window, you use specific native methods attached to tabs to build out interactive controls. Always use these exact method names:

4.1. Tab Creation (`Window:AddTab`)

local MainTab = Window:AddTab("Main Features", "General gameplay adjustments")

4.2. Action Buttons (`Tab:AddButton`)

MainTab:AddButton("Execute Action", "Description text", true, "Custom notification popup", function()
    print("Button clicked successfully!")
end)

4.3. Toggle Switches (`Tab:AddToggle`)

MainTab:AddToggle("Auto Farm Mode", "Enables background looping tasks", false, function(state)
    print("Toggle state changed to: " .. tostring(state))
end)

4.4. Sliders (`Tab:AddSlider`)

MainTab:AddSlider("WalkSpeed", 16, 300, 16, function(value)
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = value
end)

4.5. Dropdowns (`Tab:AddDropdown`)

MainTab:AddDropdown("Select Location", {"Spawn Point", "Arena", "Safe Zone"}, function(selectedOption)
    print("Selected choice: " .. selectedOption)
end)
