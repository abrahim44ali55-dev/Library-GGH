2. Window Creation & Configuration

The core window acts as the container canvas for all tabs, elements, notifications, and interactive widgets. You can configure title strings, description text headers, default themes, and toggle keybinds upon creation.

  • Title: Defines the primary name displayed on the top bar header.
  • Description: Provides secondary context or version info separated by a vertical divider.
  • Theme: Sets the initial color palette (supports multiple built-in schemes).
  • KeySystem: Enables or disables the built-in security key verification modal overlay.
local Window = Library:Create({
    Title = "Advanced Control Panel",
    Description = "Universal High-Performance System",
    Theme = "Dark Modern",
    KeySystem = true,
    Key = "VIP-2026"
})

4. Complete UI Elements & Components

Once your window and tabs are generated, you can populate them with various interactive components. Below is the exhaustive reference syntax for every element supported by our framework:

4.1. Adding Tabs

Tabs organize your options into categorized vertical scrolling pages accessible via the sidebar navigation panel.

local MainTab = Window:AddTab("Main Features", "General gameplay adjustments")

4.2. Action Buttons

Buttons execute an instant callback function when clicked by the user. Ideal for executing standalone triggers or instant script functions.

MainTab:CreateButton({
    Name = "Execute Instant Action",
    Callback = function()
        print("Button was successfully clicked!")
    end
})

4.3. Toggle Switches

Toggles provide a boolean state switch (True/False) that is widely used for loops, automatic farming routines, or persistent background tasks.

MainTab:CreateToggle({
    Name = "Auto Farm Mode",
    Default = false,
    Callback = function(State)
        print("Toggle current state: " .. tostring(State))
    end
})

4.4. Sliders

Sliders allow users to configure precise numerical values within a defined minimum and maximum range (e.g., controlling WalkSpeed or JumpPower).

MainTab:CreateSlider({
    Name = "Character WalkSpeed",
    Min = 16,
    Max = 300,
    Default = 16,
    Callback = function(Value)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = Value
    end
})

4.5. Dropdowns

Dropdown menus allow selection from a predefined list of string options, perfect for picking targets, locations, or configurations.

MainTab:CreateDropdown({
    Name = "Select Teleport Destination",
    Options = {"Spawn Point", "Arena Zone", "Safe Zone"},
    Default = "Spawn Point",
    Callback = function(SelectedOption)
        print("Chosen location: " .. SelectedOption)
    end
})

4.6. Textboxes

Textboxes let users input custom text strings dynamically for chat automation, naming utilities, or custom command execution.

MainTab:CreateTextbox({
    Name = "Custom Input Field",
    PlaceholderText = "Type command or message here...",
    Callback = function(TextValue)
        print("User typed: " .. TextValue)
    end
})
