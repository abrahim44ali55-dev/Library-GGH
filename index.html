UI Framework Documentation

Comprehensive English documentation, UI elements reference, and full production-ready templates designed for developers and AI assistants.

1. Loadstring Initialization

Fetch and initialize the UI library securely in your script execution environment.

local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/your-repo/main/library.lua"))()

2. Window Setup

Configure the main graphical window properties including title, theme settings, and visibility toggle keybind.

local Window = Library:CreateWindow({
    Title = "Advanced UI Framework",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

3. UI Elements & Components

Standard interactive elements supported by the library framework with individual code snippets.

Tab Creation: Organizes the window into structured categories.

local Tab = Window:CreateTab("Main Features")

Button Element: Executes an instant trigger function callback when clicked.

Tab:CreateButton({
    Name = "Execute Action",
    Callback = function()
        print("Button Clicked!")
    end
})

Toggle Element: A boolean switch state (true/false) ideal for looping background scripts.

Tab:CreateToggle({
    Name = "Auto Farm",
    Default = false,
    Callback = function(State)
        print("Toggle State: " .. tostring(State))
    end
})

Slider Element: Allows precise adjustments of numerical attributes.

Tab:CreateSlider({
    Name = "WalkSpeed",
    Min = 16,
    Max = 200,
    Default = 16,
    Callback = function(Value)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = Value
    end
})

4. Full Implementation Guide

A complete production-ready script template combining everything, ready to copy and send to developers or AI.

-- Load Library
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/your-repo/main/library.lua"))()

-- Create Window
local Window = Library:CreateWindow({
    Title = "Complete Script Example",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightControl
})

-- Create Tab & Elements
local MainTab = Window:CreateTab("General")

MainTab:CreateButton({
    Name = "Print Success",
    Callback = function()
        print("Script executed successfully!")
    end
})

MainTab:CreateToggle({
    Name = "Infinite Jump",
    Default = false,
    Callback = function(State)
        _G.InfJump = State
        game:GetService("UserInputService").JumpRequest:Connect(function()
            if _G.InfJump then
                game:GetService("Players").LocalPlayer.Character:FindFirstChildOfClass("Humanoid"):ChangeState("Jumping")
            end
        end)
    end
})
