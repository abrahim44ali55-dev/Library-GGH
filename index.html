4. ADD API - ALL ELEMENTS USE Add("Type", Config):
- "Section": {Title="string"}
- "Paragraph": {Title="string", Content="string"}
- "Button": {Title="string", Callback=function() end}
- "Toggle": {Title="string", Default=bool, Callback=function(v) end}
- "Slider": {Title="string", Min=number, Max=number, Default=number, Callback=function(v) end}
- "Input": {Title="string", Placeholder="string", Callback=function(text) end}
- "Dropdown": {Title="string", Options={"A","B"}, Default="A", Callback=function(v) end}
- "Colorpicker": {Title="string", Default=Color3.fromRGB(r,g,b), Callback=function(c) end}
- "Keybind": {Title="string", Default=Enum.KeyCode.F, Callback=function(k) end}
- "Code": {Code="string"}

Examples:
Main:Add("Section", {Title="Farm"})
Main:Add("Button", {Title="Btn", Callback=function() print("Hi") end})
